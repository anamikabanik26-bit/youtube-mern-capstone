# Frontend Documentation

## Technologies
- React
- Vite
- JavaScript
- React Router
- Axios

## Main Features
- Home page with video cards
- Search and category filtering
- User authentication interface
- Video watch page
- Channel and studio pages

## Setup
1. Open the frontend folder in the terminal.
2. Run `npm install`.
3. Run `npm run dev`.
4. Open the local URL shown in the terminal.
