# API Documentation

## YouTube MERN Capstone

This document describes the main API groups used in the application.

### 1. Authentication
- User registration
- User login
- JWT-based authentication

### 2. Videos
- Fetch video information
- Retrieve video lists
- Update or delete videos where supported

### 3. Channels
- Create a channel
- Retrieve channel information

### 4. Comments
- Add comments to videos
- Retrieve comments

## Testing
Test each endpoint using the actual backend routes and valid request data.

Note: Refer to the backend source code for the exact endpoint URLs,
HTTP methods, request bodies, and response formats.
