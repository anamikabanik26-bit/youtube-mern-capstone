# YouTube MERN Capstone - Setup Guide

## Prerequisites
- Node.js and npm
- MongoDB connection
- Git

## Backend Setup
1. Open the backend folder in the terminal.
2. Run `npm install`.
3. Configure the environment variables using `.env.example`.
4. Start the backend using the script defined in `backend/package.json`.

## Frontend Setup
1. Open a separate terminal.
2. Navigate to the frontend folder.
3. Run `npm install`.
4. Start the development server using `npm run dev`.

## Important
- Never commit your `.env` file or secret keys.
- Use the actual scripts and environment variable names
  defined in the project files.
